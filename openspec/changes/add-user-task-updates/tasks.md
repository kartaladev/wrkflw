# Tasks

Every Go task starts with `cc-skills-golang:golang-how-to`, and every test goes red before the code that makes it pass. Tables follow the `table-test` skill. Mocks follow `use-mockgen`. Dialect tests use `database.RunTestDatabase` (`use-testcontainers`, Docker required). Waits and deadlines follow `docs/agents/eventually-waits.md` and `docs/agents/test-deadlines.md`. All commands use `GOTOOLCHAIN=go1.26.9`. Run tests per module as CONTRIBUTING.md describes, because a bare `./...` covers only the root module.

Rulings needed first: Q1 before 4.3, Q2 before 6.3, Q3 before 1.3, Q4 before 4.1 and 7.3, and `persist-pending-commands` Q3 (the migration window) before 5.1. Every other task is independent of those answers.
